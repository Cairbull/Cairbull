# 🚀 Featured Projects

## 🌍 Travel Map

An interactive travel map built with **Laravel, Vue.js and MapLibre GL**.

The project connects an existing Joomla travel blog with a
separate Laravel backend and synchronizes travel articles
into a local Laravel database.

### Features

- Joomla → Laravel data synchronization
- Scheduled synchronization
- Local Laravel database
- REST API
- Laravel Cache
- Year-based filtering
- Vue.js frontend
- MapLibre GL

- Monkey C
- REST API
